PROJECT // 01
AWS LAB

Automated EC2 Web Server Deployment

Designed and provisioned an automated web server on Amazon Web Services using EC2, tightly-scoped Security Groups, custom RSA key pairs, and a Bash User Data bootstrap script.

AWS Console/CLI → VPC / Security Group → EC2 (t3.micro) → Nginx / Apache HTTP 80
✓ Security Group Hardening: Restricted SSH (Port 22) to authorized admin IP; opened public HTTP (Port 80) for web traffic.
✓ Zero-Touch Bootstrapping: Crafted EC2 User Data script installing web server packages, activating systemd daemon, and deploying landing page on initial launch.
✓ Key Management: Configured RSA `.pem` keys with POSIX permission enforcement (`chmod 400`) for passwordless remote administration.

Multi-Branch Git Collaboration Workflow

Architected an enterprise-style Git branching and pull request workflow preventing regressions, simulating complex merge conflicts, and enforcing automated branch protection rules.

feature/infra-setup → PR + Conflict Resolution → develop → main (Protected)
✓ Branch Protection Rules: Enforced mandatory pull request reviews, required passing checks, and disabled force-pushes (`git push -f`) on production branches.
✓ Conflict Resolution Drills: Deliberately simulated concurrent edits on identical lines across team branches, resolving conflicts cleanly using 3-way merge tools.

LINUX LAB

Linux System Daemon & Uptime Watchdog

Engineered a lightweight Bash monitoring script running via cron/systemd that inspects web server status, checks memory/disk thresholds, and automatically self-heals failing daemons.

Cron / Systemd Timer → Health Check Script → Auto-Restart Daemon → Syslog Alert
